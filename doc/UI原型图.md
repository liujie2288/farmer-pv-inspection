# 光伏巡检系统 UI/UE 原型图

> 本文档基于手机端实际截图整理，涵盖巡检员端和管理员端全部页面。
> 截图来源：`doc/book/` 目录。

---

## 一、通用交互规范

| 项目 | 说明 |
|---|---|
| **设计风格** | 简洁卡片式布局，圆角 12-16px，轻阴影 |
| **主色调** | 主色 Teal（#0D9488），辅助色 Navy（#0B3D91），背景 #F9FAFB |
| **响应式** | 移动端优先，PC 端左侧固定侧边栏 + 右侧内容区 |
| **导航模式** | 移动端：顶部栏 + 底部返回；PC 端：顶部栏 + 左侧菜单 |
| **反馈方式** | 顶部 Toast 提示（成功/失败/警告），操作前弹确认框 |

## 三、巡检员端页面

### P01 登录页

**截图：** `15_325.jpg`

**布局：**
- 居中卡片，深色渐变背景（Navy 系）
- 顶部图标 + 系统名称"光伏巡检系统"
- 表单：用户名输入框（带用户图标）、密码输入框（带锁图标 + 显示/隐藏切换）
- 底部"登录"按钮（Teal 渐变色，全宽圆角）

**交互：**
- 输入用户名和密码后点击登录
- 登录失败显示 Toast 错误提示
- 登录成功后根据角色跳转：管理员 → `/admin`，巡检员 → `/`

---

### P02 强制改密遮罩

**截图：** `16_325.jpg`

**布局：**
- 全屏半透明遮罩（bg-black/40），居中白色卡片
- 顶部盾牌图标 + 标题"首次登录，请修改密码"+ 副标题
- 表单字段：新密码、确认新密码（无原密码字段）
- "确认修改"按钮

**触发条件：**
- 新用户首次登录
- 管理员重置密码后首次登录
- 后端 `needResetPwd = true` 时自动弹出

**交互：**
- 校验：必填、至少 6 位、必须含字母和数字、两次输入一致
- 成功后自动关闭遮罩，进入系统
- 失败时刷新用户状态，防止遮罩卡死

---

### P03 首页 — 项目列表

**截图：** `17_325.jpg`

**布局：**
- 顶部标题"巡检首页"
- 搜索栏（圆角输入框，带搜索图标）
- 项目卡片列表（纵向排列，每个卡片包含）：
  - 项目名称（粗体，深色）
  - 项目地址（灰色小字）
  - 底部信息行：电站数量 + 进行中计划标签（Teal 色圆角标签）

**交互：**
- 搜索支持 500ms 防抖自动触发
- 点击卡片 → 进入该项目电站列表（P04）
- 下拉加载更多（无限滚动）

---

### P04 电站列表

**截图：** `18_325.jpg`

**布局：**
- 顶部返回箭头 + 标题"电站列表"
- 搜索栏
- 电站卡片列表，每个卡片：
  - 户主姓名（粗体）
  - 底部信息行：电站编号 | 装机容量
  - 巡检状态标签：已巡检（绿色）/ 未巡检（灰色）
  - 右上角铅笔图标（可编辑时显示）

**交互：**
- 搜索支持 500ms 防抖
- 点击卡片 → 进入电站详情（P05）
- 点击编辑图标 → 进入巡检表单（P06）

---

### P05 电站详情（只读）

**截图：** `19_325.jpg`、`20_325.jpg`

**布局：**
- 顶部返回箭头 + 户主姓名 + "电站详情"
- **基本信息卡片**：电站编号、户主姓名、装机地址、所属项目、发电户号、巡检状态
- **设备信息卡片**：逆变器序列号、品牌型号、装机容量、组件块数、规格型号、经纬度坐标
- **巡检记录卡片**：表格展示历史记录（计划名称、巡检人员、巡检时间），无记录时显示空状态

**交互：**
- 点击巡检记录行 → 进入巡检记录详情（P07）
- 长地址支持展开/收起

---

### P06 巡检表单

**截图：** `21_325.jpg` ~ `24_325.jpg`

**布局：**
- 顶部返回箭头 + 标题"巡检 - 户主姓名"
- **巡检信息卡片**（自动填充）：项目、电站、计划、编号、逆变器信息、装机容量等
- **天气选择卡片**：预设按钮（晴/多云/阴/小雨等）+ 自定义输入框
- **巡检事项区域**：
  - 按大项分组，可折叠/展开
  - 每项显示：序号 + 内容 + 正常/异常切换按钮
  - 异常时弹出异常说明文本框
  - 实测值类型显示数值输入框
  - 每个大项标题旁有完成状态指示（绿色勾）
- **底部提交按钮**：固定在底部，"提交巡检"

**交互：**
- 大项点击标题可折叠/展开
- 正常/异常按钮切换（绿色/红色高亮）
- 异常说明为可选填
- 提交前校验所有检查项必须填写
- 提交后返回上一页

---

### P07 巡检记录详情

**截图：** `25_325.jpg`、`26_325.jpg`

**布局：**
- **基本信息卡片**：巡检计划、项目名称、电站编号、户主姓名、巡检时间、巡检人、天气、GPS 坐标
- **巡检内容卡片**：
  - 按大项分组显示
  - 每项：序号 + 内容 + 正常/异常标签（绿色勾/红色叉圆角标签）
  - 异常说明（红色小字）
  - 实测值（灰色小字）
  - 现场照片：按事项分组，3 列网格展示，点击可全屏预览
- **底部按钮区**：
  - "开放编辑权限"（管理员，计划进行中且未开放时显示，琥珀色）
  - 已开放编辑权限提示（绿色文字 + 截止时间）
  - "编辑巡检记录"（有编辑权限时显示，Teal 色）
  - "查看 PDF 报告"（Navy 色）

**交互：**
- 照片点击全屏预览，支持缩放
- 编辑按钮跳转编辑页
- PDF 按钮下载并新窗口打开

## 五、核心流程

### 5.1 巡检员巡检流程

```
登录 → 首页项目列表 → 选择项目 → 电站列表 → 点击巡检按钮
  → 填写天气 → 逐项勾选正常/异常 + 填异常说明 + 拍照
  → 提交 → 返回电站列表（状态变为"已巡检"）
```

### 5.2 管理员管理流程

```
登录 → 仪表盘 → 项目管理（增删改查）
  → 电站管理（增删改查、查看巡检记录）
  → 巡检计划（创建计划、关联项目、结束计划）
  → 用户管理（增删改、重置密码）
```

### 5.3 巡检记录查看流程

```
电站详情 → 巡检记录列表 → 点击记录 → 记录详情
  → 查看检查项结果 + 照片 + 下载 PDF 报告
```
